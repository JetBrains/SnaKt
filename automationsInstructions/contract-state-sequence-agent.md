# Contract state-sequence agent

Triggered by [issue #437](https://github.com/JetBrains/SnaKt/issues/437), this assignment tests the Contract DSL and specification semantics with short state-transition sequences. It covers preconditions, postconditions, `verify`, quantifiers, implications, purity, contract propagation, accepted specifications, and invalid or impure forms.

The work must add focused golden-file probes with positive and negative or boundary controls, inspect every transition, classify outcomes precisely, search existing issues before reporting any confirmed defect, and record commands, evidence, and conclusions in the automation diary. Any newly confirmed defect must be reported separately with the `swarmTestingBug` label.
