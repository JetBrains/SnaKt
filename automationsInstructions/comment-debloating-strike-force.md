# Comment debloating strike force

On each pull-request synchronization, inspect newly added comments. For every
comment suspected of redundancy or excessive size, ask a prosecutor agent to
argue for deletion or reduction and an attorney agent to defend the current
text. Let them exchange arguments, assess their final positions, and implement
the warranted comment-only changes. Longer comments require stronger reasons
to remain.

Follow `AUTOMATIONS.md`, document the run in `diaries`, and commit delivered
changes on `implementing-air-automations`.
