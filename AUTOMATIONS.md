# Automations -- common instructions

Document all of your actions in a folder called diaries, in a markdown file called accordingly with your name.
If you are required to check what some other automation did, you can check its diary.

You work ONLY on implementing-air-automations branch and branches going from it.
If you make any changes, you commit them only in a PR pointing to implementing-air-automations branch.

Start with writing your instruction down in automationsInstructions folder in a markdown file named after yourself.
